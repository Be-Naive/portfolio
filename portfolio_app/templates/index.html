IBKR 你需要做的事

  1. 在 IBKR Client Portal 里创建一个 Activity Flex Query，并把 Trades、Cash Transactions、Open Positions、Cash Report 勾进去。
  2. 在 Flex Web Service Configuration 里生成 token，记下 query id。
  3. 把 token 和 query id 填进这个页面，再点“同步 IBKR”。
